The glossary is loaded once per workspace and shared by every file. It is applied before the translation request is sent, so the same term is rendered the same way everywhere.

That consistency matters most for long documents. When a heading changes, the glossary still wins, and the translation does not invent a new wording for it.

If a term is missing, add it there first and run sync again. Doing so keeps later retranslations aligned with the rest of the document.
