The checklist below mixes bullet lists, numbered steps, and task items.

- Prepare the workspace
  - Open the folder that contains the Markdown files
  - Confirm that the glossary is loaded
- Review the translation workflow
  1. Translate the current file
  2. Edit one paragraph in the preview
  3. Run **Sync translation**
     - Only missing blocks are translated
     - Locked blocks are skipped
- [x] Check the token budget
- [ ] Export the finished document

Each nested level keeps its original marker and indentation.
