The table below summarizes the cache states that matter during a review.

| State | Cache marker | What it means | Reference |
| :--- | :---: | --- | ---: |
| Locked | `human` | Edited by hand and protected from retranslation | [Lock guide](https://example.com/docs/lock) |
| Stale | `auto` | The source changed after the last translation | [Sync guide](https://example.com/docs/sync) |
| Copied | `copy` | Not translated; the code block is copied verbatim | [Copy rules](https://example.com/docs/copy) |

Use the link in the last column to open the full description.
