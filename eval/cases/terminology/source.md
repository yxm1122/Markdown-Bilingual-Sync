The **block** is the unit of alignment: each **heading**, **paragraph**, **table**, **code block**, and **footnote** is handled on its own. The **preview** shows the same block order on both sides, which makes a missing block easy to spot.

A **translation lock** protects hand-edited text, and the **cache** stores it together with the source hash. The **provider** receives only the blocks that need work, so the **token budget** stays predictable even in a large **workspace**.

The **glossary** keeps terminology consistent, while **stable translation** and **back-translation** reduce wording drift. A full-document **summary** can provide extra context, but it is optional.
