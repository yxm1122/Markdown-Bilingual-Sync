# Getting Started with Bilingual Sync

The **source text** is the *single source of truth*, and every translation is built from it. Use `Translate Current File` to create a translation, then open the **bilingual preview** to compare both languages.

## Before You Begin

Save the file to disk first. Unsaved buffers are skipped, and the preview shows a short reminder instead of starting a translation.

### A Quick Check

Confirm that the language pair is set to `en` → `zh-CN` and that the translation provider is configured. *Stable translation* is enabled by default, so small edits should not cause large wording changes.
