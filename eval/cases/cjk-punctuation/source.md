Run **Sync translation** after you edit the source; it updates only the blocks that changed. The `preview` panel keeps the original and the translation side by side.

Use the [glossary](https://example.com/glossary) to fix inconsistent terms, and check the **token budget** before you start a large batch.

If a block still looks wrong, open the [cache guide](https://example.com/cache), compare the `src` hash, and retranslate that block on its own.
